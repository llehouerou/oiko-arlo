# oiko-arlo

The `arlo` type of Bridge of Oiko. Oiko's own `GLOSSARY.md` defines the vocabulary this module speaks; this file holds only the Arlo-side terms it adds.

## Language

**Library**:
Arlo's cloud list of an account's recordings, videos and snapshots of every camera, kept up to 31 days and listed by whole days in the location's time zone. It lists a new recording only some seconds after Arlo announces it.
_Avoid_: archive, feed
