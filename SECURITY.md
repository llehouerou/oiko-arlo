# Security policy

oiko-arlo follows [Oiko's security policy](https://github.com/llehouerou/oiko/blob/main/SECURITY.md),
which covers every repository of Oiko's ecosystem: supported versions, response times, scope and
disclosure.

Report a vulnerability in oiko-arlo privately, through this repository's
[private vulnerability reporting](https://github.com/llehouerou/oiko-arlo/security/advisories/new).
Never in a public issue or discussion. A vulnerability in Arlo's client library goes to
[go-arlo](https://github.com/llehouerou/go-arlo)'s own reporting.
